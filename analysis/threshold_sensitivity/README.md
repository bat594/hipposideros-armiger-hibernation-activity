# Threshold-sensitivity analysis

## Scope

This module compares the primary activity metric, `group_motion_load_per_s_v5_4_primary`, generated by the V5.4-RC2 video-processing pipeline with `noise_multiplier` values k=5, k=6 and k=7. The reference setting is k=6. All other processing settings, including video selection, ROI geometry, calibration, sampling, adaptation, component-area filtering and time correction, must be held constant across threshold runs.

## Metrics

The analysis reports:

- daily total activity-load integrals and ratios relative to k=6;
- raw and daily-normalized 5-min activity profiles;
- Spearman rank correlations at 2-s and 5-min resolutions;
- Pearson and Spearman correlations between normalized 5-min profiles;
- total-variation distance and root-mean-square error between normalized profiles;
- the clock time of the maximum 10-min mean activity window; and
- the proportion of daily integrated activity recorded between 18:00 and 24:00.

For each date, comparisons use the exact timestamp intersection shared by all three thresholds. The common time series must cover at least 95% of 24 h. The analysis reports the median interval and maximum gap on the aligned time axis. No additional post hoc quality-control filter is applied in this module; upstream quality-control and export procedures must be identical across thresholds.

## Input data

The supplied configuration covers five dates:

- 2026-02-20
- 2026-02-21
- 2026-03-17
- 2026-03-30
- 2026-04-01

One daily merged CSV is required for each date and threshold (15 files in total). Each file must contain:

- `window_end_datetime`
- `group_motion_load_per_s_v5_4_primary`

The expected sampling interval is 2 s. The 15 threshold-specific input files, original thermal videos and complete per-video intermediate outputs are not included in this source archive. The analysis therefore requires local merged outputs or equivalent outputs regenerated from the same authorized source videos and ROI configuration.

## Configuration and execution

`config.template.json` defines the thresholds, reference setting, date list, input paths, time column, activity column and minimum common coverage. The relative paths are resolved from the repository root.

A local configuration file can be created from the template and populated with the 15 input paths. The local file should remain untracked; `config.local.json` is excluded by this directory's `.gitignore`.

```bash
python analysis/threshold_sensitivity/threshold_sensitivity_analysis.py \
  --config analysis/threshold_sensitivity/config.local.json
```

For the comparison to be interpretable, k=5 and k=7 outputs must be generated using the same videos, ROI configuration and upstream processing settings as the k=6 reference. The only parameter varied between runs is `--noise-multiplier`. Normal-clock dates are merged with `analysis/analyze_single_day_v54.py`. Corrected-clock dates require the corrected-view and corrected-clock aggregation procedures in `analysis/build_corrected_video_view.py` and `analysis/analyze_corrected_clock_batches_v54.py`.

| `01_daily_threshold_metrics.csv` | Daily activity-load, peak-time and night-share metrics |
| `02_pairwise_threshold_comparisons.csv` | Date-specific comparisons for each threshold pair |
| `03_pairwise_summary_across_days.csv` | Across-date summaries of pairwise agreement |
| `04_raw_5min_profiles.csv` | Raw 5-min profiles |
| `05_daily_normalized_5min_profiles.csv` | Daily-normalized 5-min profiles |
| `06_analysis_summary.txt` | Text summary of input checks and pairwise results |
| `Figure_1_raw_5min_profiles.png` | Raw 5-min profiles |
| `Figure_2_normalized_5min_profiles.png` | Daily-normalized 5-min profiles |
| `Figure_3_daily_summary_metrics.png` | Daily summary metrics across thresholds |
| `Figure_4_spearman_heatmap.png` | 5-min Spearman rank agreement |

All output tables and figures are generated locally and are not included in this source archive. A summary of the available five-date reference results is provided in `RESULTS_INTERPRETATION.md`.
