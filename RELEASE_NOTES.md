# v1.0.0

The v1.0.0 source release provides the analysis code, documentation and derived datasets for infrared-video activity quantification and the reproduction of Figures 2–7 in the associated study.

The release includes the ROI-based frame-differencing pipeline, quality-control and time-correction tools, 24-h activity-rhythm analysis, manual-validation analyses and a k=5/k=6/k=7 threshold-sensitivity module.

The archive contains processed and derived tables but does not contain original thermal videos, complete per-video intermediate outputs, the original behavioural workbook, the 15 threshold-specific input CSVs required to rerun the sensitivity analysis, or generated figure files. The included data support reproduction of the reported figures; a complete raw-video rerun requires additional source material.
