# Processed research data

The processed and derived datasets in this directory are licensed under Creative Commons Attribution 4.0 International (CC BY 4.0); see `LICENSE-DATA.md` in the repository root.

The validation tables contain one final manual reference value per clip or window. The behavioural tables contain de-identified daily and overall aggregates. The activity and review tables contain derived measurements, review classifications and applied exclusion intervals.

Original thermal videos, complete per-video intermediate outputs and the original behavioural workbook are not included. The threshold-specific daily merged inputs required for independent recalculation of the threshold-sensitivity analysis are also excluded.
