# Manual-validation data

## 10-s clips

The public validation table contains 90 clips. Each clip is represented by one final manual active-bat count paired with the corresponding machine-derived activity measures. Initial and intermediate arbitration counts are not distributed.

## 10-min windows

The public validation table contains 30 windows. Each window is represented by one final manual reference value, calculated as the arithmetic mean of the two observer-level window means. Separate observer-level counts and observer names are not distributed.

The presence of two observers in the source records does not, by itself, constitute a formal inter-observer reliability analysis. No ICC, Cohen's kappa or equivalent reliability statistic is provided in this release.
