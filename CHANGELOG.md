# Changelog

## 1.0.0

Initial public research-software release.

- Includes the ROI-based infrared-video processing pipeline and supporting quality-control, time-correction and rhythm-analysis scripts.
- Includes threshold-sensitivity analysis for k=5, k=6 and k=7.
- Includes processed validation, activity, review and behavioural tables used by the reported analyses.
- Includes figure-generation scripts and derived inputs for Figures 2–7.
- Defines separate licenses for software/documentation (MIT) and processed research data (CC BY 4.0).
- Excludes original thermal videos, complete per-video intermediate outputs, the original behavioural workbook, threshold-specific merged inputs and generated figure artwork.
