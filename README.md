# *Hipposideros armiger* Hibernation Activity Analysis

This repository contains a Python workflow for quantifying colony-level activity of hibernating *Hipposideros armiger* from infrared video. The workflow combines region-of-interest (ROI) frame differencing, activity quantification, quality control, temporal analysis and threshold-sensitivity assessment. It also includes validation tables, derived datasets and scripts used to reproduce Figures 2–7.

**Author:** Ke Ouyang, Jishou University

## Software components

- ROI-based infrared-video processing and frame-differencing activity quantification.
- Time-corrected video views, daily aggregation and quality-control procedures.
- Analysis of daily activity patterns and 24-h rhythmicity.
- Threshold-sensitivity comparison of the primary activity metric at `noise_multiplier` values k=5, k=6 and k=7.
- Manual-validation analyses and figure-reproduction scripts for Figures 2–7.

## Repository structure

```text
src/video_pipeline/             Video-processing and ROI activity-quantification code
analysis/                       Daily aggregation, quality control and rhythm analyses
analysis/threshold_sensitivity/ Threshold-sensitivity analysis
analysis/config/                Input configuration template
data/                           Validation and derived research datasets
figure_reproduction/            Figure-generation scripts for Figures 2–7

```

## Installation

Python 3.10 or later is recommended.

```bash
python -m pip install -r requirements.txt
```

A Conda environment is also provided:

```bash
conda env create -f environment.yml
conda activate hibernating-bat-analysis
```

The figure-generation scripts require genuine Arial font files. They stop with an error if Arial cannot be found; another font is not substituted automatically.

## Reproducing Figures 2–7

The derived input tables required by the figure scripts are included under `data/`.

```bash
python run_figure_reproduction.py
```

Individual figures can be generated by running the corresponding script under `figure_reproduction/`. Generated artwork is written locally and is not included in this source archive. Figure 1 is outside the scope of this release.

## Video processing

The principal video-processing entry point is:

```bash
python src/video_pipeline/bat_multi_roi_v5_4_rc2_single_decode.py --help
```

The ROI templates are located in `src/video_pipeline/config/`. Processing requires the original infrared videos and a configuration appropriate to the camera and ROI layout. The videos and complete per-video intermediate outputs are not distributed in this repository; consequently, the raw-video workflow cannot be rerun from this archive alone.

## Daily and rhythm analyses

The rhythm-analysis workflow is implemented in `analysis/run_hibernation_rhythm_analysis_v54.py`. Its configuration template is `analysis/config/rhythm_analysis_inputs_template.json`. The template contains the review decisions and date/source metadata, but the daily 2-s merged activity files are not included. Those files must be available locally before the analysis can be run. Their required columns and the analysis scope are described in `docs/REPRODUCIBILITY.md`.

## Threshold-sensitivity analysis

The module in `analysis/threshold_sensitivity/` compares the primary activity metric, `group_motion_load_per_s_v5_4_primary`, across k=5, k=6 and k=7, with k=6 as the reference setting. It evaluates total activity load, raw and daily-normalized 5-min profiles, time-series rank agreement, peak timing and the 18:00–24:00 activity share.

The supplied five-date configuration requires 15 daily merged CSV files (one for each date and threshold). These inputs are not included in the source archive. Each file must contain `window_end_datetime` and `group_motion_load_per_s_v5_4_primary`. The analysis uses the common timestamps shared by all three thresholds and requires at least 95% coverage of a 24-h day. See `analysis/threshold_sensitivity/README.md` for the method and output definitions.

## Data availability and scope

The repository includes processed validation tables, derived activity and rhythm tables, de-identified review records, daily behavioural summaries and the input tables used by Figures 2–7. It does not include:

- original infrared videos;
- complete per-video 2-s intermediate outputs;
- the original behavioural workbook;
- the 15 threshold-specific daily merged CSVs used by the threshold-sensitivity analysis; or
- generated figure artwork.

The included derived tables support reproduction of Figures 2–7. They do not constitute a complete raw-video reproduction package. Additional scope and data definitions are provided in `docs/`.
